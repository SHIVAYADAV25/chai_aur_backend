Postman is a popular tool used for testing and developing APIs.
It allows developers to send HTTP requests to a server.
Postman supports methods like GET, POST, PUT, PATCH, and DELETE.
GET is used to fetch data from the server.
POST is used to create or send new data to the server.
PUT is used to completely update existing data.
PATCH is used to partially update existing data.
DELETE is used to remove data from the server.
Request data can be sent using Body, commonly in JSON format.
Headers provide additional information about the request.
Authorization is used to authenticate users and access protected APIs.
Postman displays the server's response, status code, and response time.
Common status codes are 200 (Success), 201 (Created), 400 (Bad Request), and 404 (Not Found).
Postman supports Collections and Environment Variables to organize and manage APIs.
It is widely used to test, debug, and verify REST APIs before connecting them with frontend applications.

Example: POST /api/v1/users/register → Send request → Receive JSON response.
